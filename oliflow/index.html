Questions, answered honestly

How is OliFlow different from Zapier?

Zapier charges per task — every step in every automation burns from your monthly limit. OliFlow is a subscription: pay a flat monthly rate and run unlimited automations. No overage fees, ever. OliFlow also includes multi-path branching, code nodes, and built-in AI that Zapier doesn't offer.

Do I need to code to use OliFlow?

No. The visual drag-and-drop builder handles 95% of use cases without a line of code. For advanced users, the Code node lets you run JavaScript or Python right inside your workflow — but it's completely optional.

What are "unlimited runs"?

Every time a workflow executes — from trigger to final action — that's one run. OliFlow doesn't count or limit these. Build a workflow with 10 nodes; it still counts as 1 run. Run it 10,000 times in a day — no extra cost.

Can I connect OliFlow to my own tools?

Yes. The HTTP Request node connects to any REST API. The Webhook trigger accepts payloads from any service. The Code node can use fetch() to call anything. All 48 built-in nodes cover the most popular tools directly.

What happens if I cancel?

Your workflows are exported as JSON before access ends — you keep everything you built. Cancel anytime from your PayPal account; no retention calls or cancellation fees.
