Questions, answered honestly

How is OliFlow different from Zapier?

Zapier charges per task — every step in every automation burns from your monthly limit. OliFlow is a subscription: pay a flat monthly rate and run unlimited automations. No overage fees, ever. OliFlow also includes multi-path branching, code nodes, and built-in AI that Zapier doesn't offer.

Do I need to code to use OliFlow?

No. The visual drag-and-drop builder handles 95% of use cases without a line of code. For advanced users, the Code node lets you run real JavaScript (sandboxed via Node's vm module) or real Python 3 (a real, isolated python3 process) right inside your workflow — but it's completely optional. Note: Python's sandbox is a real OS process rather than the JavaScript path's stricter in-process isolation — see the app's own docs before enabling it in a deployment where you don't fully trust who's writing the workflows.

What are "unlimited runs"?

Every time a workflow executes — from trigger to final action — that's one run. OliFlow doesn't count or limit these. Build a workflow with 10 nodes; it still counts as 1 run. Run it 10,000 times in a day — no extra cost.

Can I connect OliFlow to my own tools?

Yes. The HTTP Request node connects to any REST API. The Webhook trigger accepts payloads from any service. The Code node's fetch() (JavaScript) / fetch() (Python) can call out too — real outbound requests, guarded against accidentally hitting a private/internal address by default, same rule as the HTTP Request node. All 48 built-in nodes cover the most popular tools directly (Slack, Stripe, Shopify, Twilio, Notion, Airtable, OpenAI, Postgres/MySQL, Supabase, PayPal, WhatsApp, Google Calendar/Sheets, and more).

What happens if I cancel?

Your workflows are exported as JSON before access ends — you keep everything you built. Cancel anytime from your PayPal account; no retention calls or cancellation fees.

Is there a mobile app?

Not a native app store listing yet — but the builder is installable straight from your browser: open OliFlow on your phone, tap "Add to Home Screen" (Android/Chrome) or "Add to Home Screen" from the Share menu (iOS/Safari), and it launches full-screen like a native app, including basic offline access to the app shell.
